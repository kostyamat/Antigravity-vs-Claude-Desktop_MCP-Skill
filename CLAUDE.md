# Agent Bridge

@.agents/AGENTS.md
@.agents/HANDOFF.md

The working notes for this machine live in `.agents/`, and only `AGENTS.md` is tracked:
the rest holds real paths and session identifiers and stays out of a public repository.
So in a fresh clone the second import resolves to nothing, which is intended — a handover
snapshot belongs to the machine that wrote it, not to everyone who clones.
